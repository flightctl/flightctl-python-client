# OsModeType

OS management mode. \"image\" indicates the OS is managed via bootc or rpm-ostree image updates. \"package\" indicates no image-based OS management is available.

## Enum

* `OsModeImage` (value: `'image'`)

* `OsModePackage` (value: `'package'`)
